## 📍 Canaux Potentiels

### Discord — ⭐ HOT
- Serveurs traders actifs (ex: communities de crypto, forex, stocks)
- Approche : Présenter la plateforme, chercher des beta testers
- Effort : Moyen | Coût : Gratuit

### Twitter/X — ⭐ HOT
- Traders partagent leurs gains, cherchent communauté
- Approche : Thread expliquant copytrading, cashback, le pourquoi
- Effort : Moyen | Coût : Gratuit

### Reddit
- r/algotrading, r/cryptocurrency, r/forex
- Approche : Commentaires authentiques (pas spam), cas d'usage
- Effort : Bas | Coût : Gratuit

### Forums Spécialisés
- Boursorama, TradingView, Blox, etc.
- Approche : Signature + engagement authentique
- Effort : Moyen | Coût : Gratuit

### Outreach Direct
- Identifier 20-30 traders influents sur Twitter
- Approche : Message perso expliquant pourquoi ça les intéresse
- Effort : Bas mais personnel | Coût : Gratuit

### Content Marketing
- Créer du contenu : guides copytrading, analyse comparatif
- Approche : SEO long-tail, TikTok/YouTube shorts
- Effort : Haut | Coût : Gratuit (juste du temps)
